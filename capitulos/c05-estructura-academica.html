Antes de empezar

Inicie sesión y compruebe la institución activa antes de crear o cambiar datos. Los permisos de este capítulo indican qué acciones puede hacer usted; tener un rol no garantiza que tenga todos esos permisos.

Período académico
Tramo con fechas propias al que pertenecen los grupos de estudiantes. Marcarlo como activo permite ofrecerlo al elegir el período de trabajo y al crear grupos.
Período de trabajo
Período académico que usted elige para consultar y registrar datos. Crear un período académico no sustituye esa elección.
Facultad y escuela o departamento
La facultad agrupa escuelas o departamentos de una institución. Cada materia pertenece a una escuela o departamento.
Tipo de grupo
Categoría que se asigna a un grupo de estudiantes. Crear un tipo no crea una sección ni agrega estudiantes.

Prepare primero la facultad y la escuela o departamento; después podrá elegir la escuela de cada materia. Para asignar instrumentos a una materia debe existir al menos un período académico.

Las fechas de matrícula se explican en Abrir la matrícula de un período. Las carreras y los planes de estudios se explican en Crear carreras y planes de estudio.

Consultar los períodos académicos

Para qué sirve

Para revisar las fechas, la disponibilidad y la cantidad de grupos de estudiantes que dependen de cada período académico.

Quién puede hacerla

Quien tenga el permiso periodos.ver, tanto para el listado como para el detalle.

Dónde está

Configuración › Año lectivo › Períodos académicos.

Pasos

  1. Escriba un nombre, código, año o el texto de Ciclo en Buscar.
  2. Pulse Buscar.
  3. Elija una opción en Tipo si necesita limitar la lista; al elegirla se actualizan los resultados.
  4. Revise las columnas Fechas, Estado, Grupos y Estudiantes.
  5. Pulse el nombre del período académico para abrir su detalle.
  6. Revise Fechas, Identificación y Qué depende de este período.

Qué pasa después

El detalle muestra las fechas y el avance del período académico. Activo o Inactivo indica su disponibilidad; Próximo, En curso o Terminado depende de las fechas. Consultar el detalle no cambia el período de trabajo.

Errores frecuentes

  • Ningún período coincide con la búsqueda: pruebe otro texto o pulse Quitar filtros.
  • Faltan filas por revisar: cambie Por página o use los números de página al pie de la tabla.

Crear o editar un período académico

Para qué sirve

Para preparar un período académico con su identificación y sus fechas, o corregir los datos de uno que ya existe.

Quién puede hacerla

Quien tenga periodos.crear para crear o periodos.editar para editar. El listado requiere periodos.ver.

Dónde está

Configuración › Año lectivo › Períodos académicos, botón Nuevo período o icono Editar de la fila.

Pasos

  1. Pulse Nuevo período para crear, o Editar junto al período académico que desea cambiar.
  2. Elija el Tipo: Semestre, Cuatrimestre, Trimestre, Anual o Personalizado.
  3. Escriba el Año, entre 2020 y 2100.
  4. Elija el Número en el año, del 1 al 4.
  5. Revise Ciclo, por ejemplo I o II.
  6. Revise el Nombre y el Código; al crear se sugieren a partir del tipo, el año y el número, y usted puede cambiarlos.
  7. Escriba las fechas de Inicio y Fin en Fechas; el fin debe ser posterior al inicio.
  8. Complete Matrícula si corresponde, siguiendo Abrir la matrícula de un período.
  9. Revise la casilla Período activo según quiera ofrecerlo para trabajar y crear grupos de estudiantes.
  10. Pulse Crear período si es nuevo, o Guardar cambios si lo está editando.

Qué pasa después

PDI vuelve al listado y muestra «Período académico creado exitosamente» o «Período académico actualizado exitosamente». Al editar, los grupos de estudiantes y los estudiantes conservan el período académico: cambiar las fechas no los mueve.

Errores frecuentes

  • «Ya existe un período con este código»: use otro Código o edite el período académico existente.
  • «Ya existe un período para este año y ciclo»: revise Año y Ciclo antes de crear otro.
  • «La fecha de fin debe ser posterior a la de inicio.»: corrija Fin.

  • Consultar los períodos académicos

Desactivar, reactivar o eliminar un período académico

Para qué sirve

Para dejar de ofrecer un período académico conservando su historial, volver a ofrecerlo o eliminar uno que no tenga grupos de estudiantes ni estudiantes.

Quién puede hacerla

Quien tenga periodos.editar para desactivar o reactivar, o periodos.eliminar para eliminar. El listado requiere periodos.ver.

Dónde está

Configuración › Año lectivo › Períodos académicos, iconos Editar y Eliminar.

Pasos

Desactivar o reactivar

  1. Pulse Editar en la fila del período académico.
  2. Desmarque Período activo para desactivarlo, o márquela para reactivarlo.
  3. Pulse Guardar cambios.

Eliminar

  1. Pulse Eliminar en la fila del período académico.
  2. Revise la identificación y el aviso de eliminación.
  3. Pulse Eliminar definitivamente solo si desea borrarlo; para salir sin borrar, pulse Cancelar.

La eliminación no se puede deshacer. La pantalla avisa si también se eliminarán ofertas de materias asociadas al período académico.

Qué pasa después

Al desactivar, el período académico queda Inactivo y conserva su historial. Al reactivar queda Activo. Al eliminar, desaparece del listado y se muestra «Período académico eliminado exitosamente».

Errores frecuentes

  • La papelera está deshabilitada y avisa «No se puede eliminar: tiene grupos o estudiantes»: edite el período académico y desmarque Período activo.
  • La pantalla de eliminación indica que tiene grupos de estudiantes o estudiantes: use Editar y desactivar si tiene permiso para editar.

Consultar, crear o editar una facultad

Para qué sirve

Para organizar las escuelas o departamentos de una institución bajo una facultad y mantener sus datos de contacto.

Quién puede hacerla

Quien tenga instituciones.ver para consultar el listado y el detalle, instituciones.crear para crear o instituciones.editar para editar.

Dónde está

Administración › Instituciones › Facultades.

Pasos

Consultar

  1. Escriba un nombre, código o el nombre del decano o decana en Buscar.
  2. Pulse Buscar.
  3. Elija Activas o Inactivas en Estado si necesita limitar la lista.
  4. Pulse el nombre de la facultad para ver sus escuelas o departamentos y sus datos de contacto.

Crear o editar

  1. Pulse Nueva facultad en el listado, o Editar en una facultad existente.
  2. Compruebe la Institución que muestra el formulario; si aparece una lista al crear, elija la institución.
  3. Escriba el Nombre, por ejemplo Facultad de Ejemplo.
  4. Complete el Código si lo utiliza.
  5. Complete Decano o decana, Correo y Teléfono si dispone de esos datos.
  6. Revise la casilla Activa.
  7. Pulse Crear facultad o Guardar cambios, según corresponda.

Qué pasa después

Se abre el detalle con «Facultad creada.» o «Facultad actualizada.». Desde Agregar escuela puede crear una escuela o departamento con la facultad ya elegida. La institución de una facultad existente no se cambia.

Errores frecuentes

  • Ya existe una facultad con ese nombre en la institución: revise el listado y edite la existente o use un nombre distinto.
  • Ninguna facultad coincide con el filtro: pulse Quitar filtros o cambie el texto o el estado.

Consultar, crear o editar una escuela o departamento

Para qué sirve

Para organizar las materias, los profesores y los coordinadores de una escuela o departamento dentro de su facultad.

Quién puede hacerla

Quien tenga instituciones.ver para consultar el listado y el detalle, instituciones.crear para crear o instituciones.editar para editar.

Dónde está

Administración › Instituciones › Escuelas y departamentos. También puede usar Agregar escuela desde el detalle de una facultad.

Pasos

Consultar

  1. Escriba un nombre, código o el nombre que figura en Director o directora en Buscar.
  2. Pulse Buscar.
  3. Elija la Facultad o el Estado si necesita limitar los resultados.
  4. Pulse el nombre de la escuela o departamento para revisar Datos de la escuela y Coordinación.

Crear o editar

  1. Pulse Nueva escuela en el listado, o Editar en una escuela o departamento existente.
  2. Elija la Facultad.
  3. Escriba el Nombre, por ejemplo Escuela de Ejemplo.
  4. Complete el Código si lo utiliza.
  5. Complete Director o directora, Correo y Teléfono si dispone de esos datos.
  6. Revise la casilla Activa.
  7. Pulse Crear escuela o Guardar cambios, según corresponda.

Qué pasa después

Al crear, PDI vuelve al listado con «Escuela/Departamento creado exitosamente.». Al editar, abre el detalle con «Escuela actualizada.». Los coordinadores y los profesores se administran desde el detalle; las materias se asocian desde el formulario de cada materia.

Errores frecuentes

  • «No hay facultades activas.»: cree una facultad o active la que corresponda antes de crear la escuela o departamento.
  • Ya existe una escuela o departamento con el mismo nombre en esa facultad: revise el listado y edite la existente o cambie el nombre.
  • «La facultad debe ser de la misma institución que la escuela.»: al editar, elija una facultad de la misma institución.
  • El listado indica Sin coordinador: abra ese enlace y asigne un coordinador si tiene el permiso necesario.

Desactivar, reactivar o eliminar una facultad o escuela

Para qué sirve

Para dejar de ofrecer una facultad o escuela o departamento sin perder su historial, o eliminarla si ya no tiene datos que impidan hacerlo.

Quién puede hacerla

Quien tenga instituciones.editar para cambiar el estado o instituciones.eliminar para eliminar. Los listados requieren instituciones.ver.

Dónde está

Administración › Instituciones › Facultades o Administración › Instituciones › Escuelas y departamentos, en los iconos de cada fila.

Pasos

Desactivar o reactivar

  1. Localice la facultad o escuela o departamento en su listado.
  2. Pulse el icono Desactivar si está activa, o Activar si está inactiva.
  3. Revise el nuevo Estado en el listado; si tenía un filtro por estado, cambie ese filtro para encontrarla.

Eliminar

  1. Pulse el icono Eliminar de la fila.
  2. Revise el nombre y el aviso de la pantalla de eliminación.
  3. Pulse Eliminar definitivamente si desea borrarla, o Cancelar para conservarla.

La eliminación no se puede deshacer. Una facultad con escuelas o departamentos no se elimina. Una escuela o departamento con materias, profesores o coordinadores tampoco se elimina; desactívela para conservar su historial.

Qué pasa después

La facultad o escuela o departamento cambia entre Activa e Inactiva. También puede cambiar ese estado desde Editar, con la casilla Activa y Guardar cambios. Si se elimina, desaparece del listado.

Errores frecuentes

  • La papelera de una facultad está deshabilitada: tiene escuelas o departamentos. Use Desactivar.
  • La papelera de una escuela o departamento está deshabilitada: tiene materias, profesores o coordinadores. Use Desactivar.
  • La eliminación avisa que está en uso: conserve el elemento y desactívelo; el sistema no pudo eliminarlo.

Tareas relacionadas

  • Consultar, crear o editar una facultad
  • Consultar, crear o editar una escuela o departamento

Asignar o quitar coordinadores

Para qué sirve

Para indicar qué usuarios coordinan una escuela o departamento. En instituciones de nivel Superior también puede asignar coordinadores a una facultad para la aprobación del empadronamiento de sus carreras.

Quién puede hacerla

Quien tenga el permiso coordinacion.asignar. En la instalación estándar lo reciben los roles Super Administrador y Administrador. Para abrir los listados y detalles necesita instituciones.ver. El usuario que se asigna debe tener el rol Coordinador y pertenecer a la misma institución.

Dónde está

Administración › Instituciones › Escuelas y departamentos, detalle, Coordinación. Para una facultad de una institución de nivel Superior: Administración › Instituciones › Facultades, detalle, Coordinación de la facultad.

Pasos

Asignar

  1. Abra el detalle de la escuela o departamento, o de la facultad.
  2. Elija el usuario en Agregar coordinador.
  3. Pulse Agregar en la escuela o departamento, o Asignar en la facultad.

Quitar

  1. Localice al coordinador en la lista del detalle.
  2. Pulse el icono para quitar al coordinador en la escuela o departamento, o Quitar en la facultad.
  3. Confirme que desea quitarlo de esa escuela o departamento, o de esa facultad.

Qué pasa después

El usuario aparece o deja de aparecer en la lista de coordinadores. En una escuela o departamento se muestra «Coordinador asignado a la escuela.» o «Coordinador retirado de la escuela.». En una facultad se muestra «Coordinador asignado a la facultad.» o «Coordinador retirado de la facultad.».

Los coordinadores de una escuela o departamento consultan los grupos de estudiantes, los estudiantes y las evaluaciones de sus materias. Tener profesores registrados en la escuela no sustituye la asignación de la escuela a cada materia.

Errores frecuentes

  • «No hay más cuentas con el rol Coordinador.»: revise los usuarios y sus roles en capítulo 3, Roles, permisos y usuarios.
  • «La cuenta no existe en su institución o no tiene el rol Coordinador.»: compruebe el rol y la pertenencia del usuario a la institución.
  • La escuela o departamento avisa que todavía no tiene materias: asigne la escuela en cada materia; hasta entonces sus coordinadores no verán ningún grupo de estudiantes.
  • No aparece Coordinación de la facultad: ese apartado solo se muestra en instituciones de nivel Superior y con permiso para asignar coordinación.

Registrar los profesores de una escuela

Para qué sirve

Para indicar en qué escuelas o departamentos trabaja un profesor, anotar su porcentaje de jornada y elegir cuál se muestra como principal en su ficha.

Quién puede hacerla

Quien tenga coordinacion.asignar. Para abrir el detalle de la escuela o departamento necesita instituciones.ver.

Dónde está

Administración › Instituciones › Escuelas y departamentos, detalle, Coordinación › Profesores.

Pasos

Agregar un profesor

  1. Elija al profesor en Agregar profesor.
  2. Escriba el Porcentaje de jornada (opcional), entre 0 y 100, o déjelo vacío.
  3. Pulse Agregar junto al profesor elegido.

Actualizar o quitar

  1. Cambie Jornada (%) en la fila del profesor si necesita corregirla.
  2. Marque Hacer principal si desea que esta escuela o departamento sea la que aparece en la ficha del profesor.
  3. Pulse el icono Guardar de esa fila.
  4. Pulse Quitar y confirme si necesita retirar al profesor de esta escuela o departamento.

Qué pasa después

PDI muestra «Profesor agregado a la escuela.», «Datos del profesor en la escuela actualizados.» o «Profesor retirado de la escuela.». La jornada es informativa. Si el profesor no tiene otra escuela o departamento principal, la primera que agrega pasa a ser la principal.

Si retira al profesor de su escuela o departamento principal, otra de las que conserva pasa a ser la principal; si no queda ninguna, su ficha queda sin escuela. La elección de principal no cambia lo que consultan los coordinadores: eso depende de la escuela de cada materia.

Errores frecuentes

  • «El porcentaje de jornada debe estar entre 0 y 100.»: corrija el número o deje el campo vacío.
  • Sin cuenta vinculada: el profesor todavía no está vinculado a un usuario. Sus grupos de estudiantes son visibles para la coordinación, pero sus evaluaciones y rúbricas quedan sin identificar; revise su ficha en capítulo 6, Profesores.
  • «Todos los profesores de la institución ya trabajan en esta escuela.»: no hay otro profesor disponible para agregar.

Tareas relacionadas

  • Asignar o quitar coordinadores
  • Capítulo 6, Profesores

Obtener el reporte de escuelas o departamentos

Para qué sirve

Para revisar o imprimir las escuelas o departamentos, agrupados por institución y facultad, con los filtros del listado.

Quién puede hacerla

Quien tenga instituciones.ver.

Dónde está

Administración › Instituciones › Escuelas y departamentos, botón Reporte imprimible.

Pasos

  1. Use Buscar, Facultad y Estado para dejar en el listado las escuelas o departamentos que necesita.
  2. Pulse Buscar para aplicar el texto escrito antes de abrir el reporte.
  3. Pulse Reporte imprimible.
  4. Revise los filtros aplicados, los totales y las columnas Escuela / Departamento, Código, Director y Estado.
  5. Pulse Imprimir / Guardar como PDF para abrir las opciones de impresión del navegador.

Qué pasa después

El navegador ofrece sus opciones para imprimir o guardar el reporte. El reporte incluye la fecha y hora de generación; no cambia las escuelas o departamentos.

Errores frecuentes

  • «No hay Escuelas/Departamentos que coincidan con los filtros aplicados.»: vuelva al listado, quite o cambie los filtros y abra de nuevo el reporte.

Consultar, crear o editar una materia

Para qué sirve

Para mantener las materias de la institución, sus créditos y la escuela o departamento al que pertenecen. Esa elección determina qué coordinación consulta sus grupos de estudiantes y en qué escuela se cuentan en los reportes.

Quién puede hacerla

Quien tenga materias.ver para el listado, materias.ver_detalles para el detalle, materias.crear para crear o materias.editar para editar.

Dónde está

Configuración › Estructura académica › Materias.

Pasos

Consultar

  1. Escriba un nombre, código o parte de la descripción en Buscar.
  2. Pulse Buscar.
  3. Elija un Tipo si desea limitar los resultados.
  4. Pulse el nombre de la materia para revisar sus datos, sus requisitos, sus instrumentos de evaluación y sus grupos de estudiantes con los profesores que la imparten.

Crear o editar

  1. Pulse Nueva materia en el listado, o Editar en una materia existente.
  2. Escriba el Nombre y el Código, por ejemplo Materia de Ejemplo y EJ101.
  3. Elija el Tipo, o deje Sin especificar.
  4. Escriba los Créditos, entre 0 y 10.
  5. Elija Escuela a la que pertenece.
  6. Escriba la Descripción si necesita explicar los contenidos o el enfoque de la materia.
  7. Revise la casilla Materia activa.
  8. Pulse Crear materia o Guardar cambios, según corresponda.

Qué pasa después

PDI vuelve al listado con «Materia creada exitosamente» o «Materia actualizada exitosamente». Cambiar la escuela o departamento cambia qué coordinadores ven sus grupos de estudiantes y dónde la cuentan los reportes. Los profesores que imparten la materia se asignan desde el grupo de estudiantes.

Errores frecuentes

  • «Ya existe una materia con este código»: cambie el Código o edite la materia existente.
  • «Seleccione la escuela de la materia.»: elija Escuela a la que pertenece; si no hay opciones, prepare una escuela o departamento activo.
  • Sin escuela en el listado: ninguna coordinación ve sus grupos de estudiantes ni se cuenta en los reportes por escuela; edite la materia y asígnele la escuela o departamento.
  • Ninguna materia coincide con la búsqueda: pulse Quitar filtros o pruebe otro nombre, código o tipo.

Definir los requisitos de una materia

Para qué sirve

Para indicar qué materias debe haber cursado antes el estudiante para inscribir una materia.

Quién puede hacerla

Quien tenga materias.editar. Para abrir el detalle necesita materias.ver_detalles y para llegar desde el listado, materias.ver.

Dónde está

Configuración › Estructura académica › Materias, nombre de la materia, apartado Requisitos.

Pasos

  1. Abra el detalle de la materia que pide haber cursado otra antes.
  2. Elija esa otra materia en Agregar requisito.
  3. Pulse Agregar.
  4. Revise la lista de requisitos y cualquier aviso que aparezca junto a ellos.
  5. Pulse el icono Quitar requisito si necesita retirar uno de la lista.

Qué pasa después

La lista se actualiza y muestra qué materias se deben cursar antes. La piden muestra las materias que tienen a esta como requisito. Si aparece un aviso sobre los bloques de un plan de estudios, revise el orden de las materias de ese plan.

Errores frecuentes

  • No aparece la materia que desea agregar: la lista ofrece materias activas de la misma institución, excluye la propia y las que ya son requisitos.
  • El sistema avisa que quedarían bloqueadas las dos materias: el requisito elegido ya pide esta materia, directamente o a través de otras. Corrija esa dependencia antes de agregarlo.
  • «Ese requisito ya no está.»: ya se había quitado; revise la lista actual.

Tareas relacionadas

  • Crear carreras y planes de estudio
  • Inscribir y retirar materias

Consultar, asignar o quitar instrumentos de una materia

Para qué sirve

Para indicar qué instrumentos de evaluación se usan en una materia durante un período académico y revisar cuánto suman en la nota.

Quién puede hacerla

Quien tenga materias.ver_instrumentos para consultar todos los períodos o materias.asignar_instrumentos para abrir la pantalla de asignación y asignar. Para quitar desde cualquiera de esas pantallas necesita además materias.quitar_instrumentos. El listado de materias requiere materias.ver.

Dónde está

Configuración › Estructura académica › Materias, número de la columna Instrumentos para consultar, o icono Asignar instrumentos. También está el enlace Asignar instrumentos en el detalle de la materia.

Pasos

Consultar y asignar

  1. Pulse el número de Instrumentos de la materia para revisar sus asignaciones por período académico.
  2. Pulse Asignar instrumentos para abrir el formulario de asignación; si la materia aún no tiene instrumentos, use ese icono desde el listado.
  3. Elija el Período; la lista de asignados se actualiza.
  4. Elija el Instrumento en Agregar instrumento.
  5. Revise el Orden y la casilla Obligatorio.
  6. Revise cuánto sumaría la nota con el instrumento elegido.
  7. Pulse el botón Asignar a seguido del nombre del período académico.
  8. Pulse Ver todos los períodos si necesita revisar de nuevo todas las asignaciones y tiene permiso para consultarlas.

Quitar

  1. Localice el instrumento de evaluación en el período académico correspondiente.
  2. Pulse el icono Quitar de la materia.
  3. Confirme que desea quitarlo de la materia en ese período académico.

Qué pasa después

Al asignar aparece «Instrumento asignado a la materia.». Al quitar aparece «Instrumento quitado de la materia. Sus evaluaciones se conservan.». El instrumento de evaluación se usa una sola vez en cada materia, aunque las asignaciones se consulten por período académico.

La columna Vale muestra la suma de los porcentajes de sus rúbricas. La pantalla avisa cuánto falta o sobra para llegar al 100 % del período académico. Esos porcentajes se ajustan en las rúbricas del instrumento, como se explica en capítulo 12, Rúbricas e instrumentos.

Errores frecuentes

  • La institución no tiene períodos académicos: cree primero un período académico.
  • No quedan instrumentos activos sin asignar a la materia: cree otro instrumento de evaluación o revise en qué período académico ya está asignado el que busca.
  • El sistema indica que el instrumento ya está en la materia: no puede asignarlo de nuevo en otro período académico de esa misma materia.
  • Sin rúbrica: asignar: agregue una rúbrica al instrumento de evaluación para poder evaluar.

Desactivar, reactivar o eliminar una materia

Para qué sirve

Para dejar de ofrecer una materia conservando su historial, volver a ofrecerla o eliminar una que no esté en uso.

Quién puede hacerla

Quien tenga materias.editar para cambiar la disponibilidad o materias.eliminar para eliminar. El listado requiere materias.ver.

Dónde está

Configuración › Estructura académica › Materias, iconos Editar y Eliminar.

Pasos

Desactivar o reactivar

  1. Pulse Editar en la materia.
  2. Desmarque Materia activa para desactivarla, o márquela para reactivarla.
  3. Pulse Guardar cambios.

Eliminar

  1. Pulse Eliminar en la materia.
  2. Revise el nombre y los datos de la pantalla de eliminación.
  3. Pulse Eliminar definitivamente para borrarla, o Cancelar para conservarla.

La eliminación no se puede deshacer. Si la materia tiene grupos de estudiantes, profesores, instrumentos de evaluación, lecciones u otros datos asociados, consérvela y desactívela.

Qué pasa después

La materia queda Inactiva o Activa. Desactivada conserva su historial. Si se elimina, desaparece del listado con «Materia eliminada exitosamente».

Errores frecuentes

  • La papelera está deshabilitada: la materia está en uso. Pulse Editar y desmarque Materia activa.
  • «No se puede eliminar: la materia está en uso.»: revise los datos asociados que muestra la pantalla; también pueden impedirlo la asistencia, los cuadernos calificadores o los requisitos. Use Editar y desactivar si tiene permiso para editar.

Consultar, crear o editar un tipo de grupo

Para qué sirve

Para preparar las categorías con las que se organizan los grupos de estudiantes y revisar cuáles usan cada tipo.

Quién puede hacerla

Quien tenga tipos_grupo.ver para el listado, tipos_grupo.ver_detalles para el detalle, tipos_grupo.crear para crear o tipos_grupo.editar para editar.

Dónde está

Configuración › Estructura académica › Tipos de grupo.

Pasos

Consultar

  1. Revise las columnas Nombre, Estado y Grupos.
  2. Pulse el nombre del tipo de grupo, o su cantidad de grupos de estudiantes, para abrir el detalle.
  3. Revise Grupos de este tipo, con sus períodos académicos y estados.

Crear o editar

  1. Pulse Nuevo tipo en el listado, o Editar en el tipo de grupo existente.
  2. Escriba el Nombre, por ejemplo Sección.
  3. Elija Activo o Inactivo en Estado.
  4. Pulse Crear tipo o Guardar cambios, según corresponda.

Qué pasa después

Se abre el detalle del tipo de grupo. Un cambio de nombre se refleja en todos los grupos de estudiantes que lo usan. Los tipos activos se ofrecen al crear o editar grupos de estudiantes; los ya existentes conservan un tipo que se desactive.

Errores frecuentes

  • «Ya existe un tipo de grupo con este nombre»: use otro Nombre o edite el existente.
  • El detalle indica que ningún grupo de estudiantes usa el tipo todavía: asígnelo al crear o editar un grupo de estudiantes, como se explica en capítulo 7, Estudiantes y grupos.

Cambiar el estado o eliminar un tipo de grupo

Para qué sirve

Para dejar de ofrecer un tipo de grupo, volver a ofrecerlo o eliminarlo si ningún grupo de estudiantes lo usa.

Quién puede hacerla

Quien tenga tipos_grupo.cambiar_estado para usar el control del listado, tipos_grupo.editar para cambiar el estado en el formulario o tipos_grupo.eliminar para eliminar. El listado requiere tipos_grupo.ver.

Dónde está

Configuración › Estructura académica › Tipos de grupo.

Pasos

Cambiar el estado

  1. Localice el tipo de grupo en el listado.
  2. Pulse el control Activo o Inactivo de su fila para cambiar al otro estado.
  3. Compruebe el nuevo texto del control y la cantidad de tipos activos que aparece sobre la tabla.

Eliminar

  1. Pulse el icono Eliminar del tipo de grupo.
  2. Revise el nombre y la cantidad de grupos de estudiantes que lo usan.
  3. Pulse Eliminar definitivamente para borrarlo, o Cancelar para conservarlo.

La eliminación no se puede deshacer. Si un grupo de estudiantes usa el tipo, desactívelo o cambie el tipo de ese grupo antes de intentar eliminarlo.

Qué pasa después

El estado cambia entre Activo e Inactivo sin salir del listado. También puede cambiarlo desde Editar, elegir el Estado y pulsar Guardar cambios. Si lo elimina, el tipo desaparece del listado.

Errores frecuentes

  • La papelera está deshabilitada: uno o más grupos de estudiantes usan ese tipo; desactívelo para conservarlos.
  • El estado aparece como texto y no como control: no tiene el permiso para cambiarlo desde el listado. Use Editar si dispone del permiso de edición.
  • «No se pudo cambiar el estado»: el cambio no se completó; revise el mensaje y vuelva a intentarlo.
